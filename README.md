# ATOMIC · Habit Tracker

A calendar and habit tracker in one, built as a private, offline-first PWA for iPhone. Every habit ends the day with an answer (done or skipped), and a single evening push closes the day.

- Your data stays on your phone (IndexedDB). No accounts, no analytics, no third-party requests.
- Designed end to end in Figma first; this repo builds it.
- Build spec, rules and decisions: [CLAUDE.md](CLAUDE.md)

Status: M0, build test 0 (does data and push survive on a real iPhone?).
